# WOLF Web Application Client

A modern web-based interface for interacting with WOLF agents through the gateway.

## Features

- **Real-time Communication**: WebSocket-based connection for instant agent responses
- **Dynamic Agent Configuration**: Configure agent parameters directly from the UI
- **Modern UI**: Clean, responsive design with gradient backgrounds and smooth animations
- **Streaming Support**: Toggle between standard and streaming response modes
- **Context Management**: Reset agent context with a single click
- **Status Indicators**: Visual feedback for connection status and agent activity
